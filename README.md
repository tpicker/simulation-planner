# Simulation Planner

Plan a simulation's purpose, learning outcomes, scenes, student instructions, and publishing details.

## Interactive web app

Open `index.html` in a browser. Add scenes as needed. The app keeps your draft in the current browser. Choose **Copy summary** or **Print / Save PDF** to export the plan, or open **Summary** and choose **Save text**.

## Canvas LMS

Open `simulation-planner-canvas.html` in a text editor. Paste the HTML into a Canvas Page's HTML editor and save the page. Replace the bracketed prompts while editing the page. Copy the Plan summary manually or use your browser's print menu to print or save as PDF.
